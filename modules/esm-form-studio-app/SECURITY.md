# Security Policy

## Reporting a Vulnerability

Please report security issues privately. Don't open a public issue, pull request, forum thread, or Slack message.

- By email to <security@openmrs.org>. Emails are automatically posted on the private Security Talk category, where they are immediately available for review and discussion by relevant OpenMRS community members in technical or operational leadership positions.
- On GitHub, use [private vulnerability reporting](https://github.com/openmrs/openmrs-core/security/advisories). This lets us use GitHub's Security Advisory and CVE tools. Please include as much detail as possible: the steps to reproduce, the affected versions, the expected and actual results, and anything else that helps us react faster. We prefer a text write-up with a proof-of-concept over screenshots or videos.

Please don't test against any system holding real patient data.

For our full vulnerability management process, severity targets, and disclosure steps, see [om.rs/security101](https://om.rs/security101).
