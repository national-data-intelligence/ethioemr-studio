# Start a form from scratch

Choose **From scratch** on the start page. A window called **"New form: the basics"** opens.

| Field | What to write |
|---|---|
| Form name | What the form is called in the EMR, for example "Cardiac History Sheet". It can't be the name of another form. |
| Description | What the form records, for whom, and when it's used. Aim for 18 to 40 words; a counter shows how many you have. |
| Encounter type | Choose from the list. Only the project's encounter types are offered. |
| Version | Leave it as it is unless told otherwise. |
| UUID | Made from the name for you. You don't type it. |

Press **Create form**. The editor opens with the standard structure every EthioEMR form has:

- the **Visit Details** page (visit date, provider and the other standard fields), and
- a starter page, **"Vital Signs & Assessment"**, to build on or rename.

**Already have the form as JSON?** (JSON is the text file a form is stored as.) Press **Skip: I will paste a
JSON**, paste it into the **Schema editor** view, and render it.
