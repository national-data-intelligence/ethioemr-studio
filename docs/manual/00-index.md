# Form Studio user manual

Form Studio is where EthioEMR forms are made and fixed. You start a form (from nothing, from a Bahmni export, or
from our Excel template), edit it on screen, let Form Studio check it, and download the files that a reviewer adds
to the content repository. Form Studio never changes a live EMR. A form reaches a facility only after a person
reviews the files and they are released.
